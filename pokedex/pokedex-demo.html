Con el gateway Node corriendo, la app le pide todo a él: elige el proveedor (pokemontcg.io o Scrydex), guarda la API key fuera del navegador, cachea y absorbe los cortes 502. Sin gateway funciona igual en modo directo contra pokemontcg.io, que es gratis pero inestable. Scrydex sólo funciona vía gateway: exige plan de pago, API key y Team ID, y su documentación prohíbe expresamente poner la key en el cliente.

Persistencia local — tu avance vive en localStorage de este navegador con la clave pokedex_tcg_alpha_v1. El catálogo de cartas se cachea en IndexedDB por 7 días para respetar el rate limit de pokemontcg.io.
